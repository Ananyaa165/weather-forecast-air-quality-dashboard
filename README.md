# Weather Forecast & Air Quality Analytics Dashboard

## Project Overview

An interactive Weather Analytics Dashboard developed using Microsoft Power BI to visualize weather conditions, forecast trends, and air quality indicators.

The dashboard provides an overview of current weather conditions and upcoming forecasts while presenting important environmental metrics through interactive visualizations.

## Dashboard Preview

![Weather Analytics Dashboard](weather_dashboard.png)

## Dashboard Features

### 1. Weather Overview
- Current temperature and weather conditions.
- City selection and comparison.
- Weekly weather forecast.

### 2. Weather Forecast Analysis
- Temperature trends across the week.
- Daily weather conditions.
- Sunrise and sunset information.
- Probability of rainfall.

### 3. Environmental Monitoring
- Air Quality Index (AQI).
- Pollutant measurements including PM10, PM2.5, CO, CO2, NO2, SO2, and O3.
- Humidity and visibility.
- UV index and wind speed.
